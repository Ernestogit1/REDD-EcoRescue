| cd mobile       |
| npm i           | EACH FOLDER
-------------------

--------------------------------------------------------------------------------------------------------

WEB ---- HOW TO RUN?

1. Start the server
-------------------
| cd server       |
| npm start       |
-------------------

2. Start the web
-------------------
| cd web          |
| npm run dev     |
-------------------

3. You can now run the web via localhost
4. To start each game 
-------------------
| cd card         |
| cd color        |
| cd match        |
| cd puzzle       |
| npm run dev     |
-------------------

5. To view the analytics
-------------------
| cd admin        |
| npm run dev     |
-------------------

--------------------------------------------------------------------------------------------------------

MOBILE ---- HOW TO RUN?

*ipconfig - look at the current IP address and paste it in the .env

1. Start the server
-------------------
| cd mobile       |
| npx expo start  |
-------------------

2. Download Expo Go
3. Scan or Type the URL the MetroBundler will output
